개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-09-29

1. 수집하는 정보

이 도구는 운영자 본인이 Google 계정으로 승인한 범위 안에서만 YouTube Data API와 YouTube Analytics API를 사용합니다. 사용하는 정보는 운영자 채널에 업로드한 영상의 메타데이터(제목·설명·공개 상태)와 통계(조회수·좋아요·댓글 수·평균 시청 시간)뿐입니다. 다른 사용자의 개인정보는 수집하지 않습니다.

2. 이용 목적

영상 업로드, 공개 상태 변경, 업로드한 영상의 성과 확인에만 사용합니다.

3. 보관 및 공유

OAuth 토큰과 통계는 운영자의 로컬 컴퓨터에만 저장되며 제3자에게 판매·공유·전송하지 않습니다.

4. 권한 철회

Google 계정 설정(myaccount.google.com/permissions)에서 언제든 접근 권한을 철회할 수 있습니다. YouTube API 서비스 이용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

English summary

This tool uses the YouTube Data API and YouTube Analytics API only within the scopes granted by the operator for the operator's own channel. It processes only metadata and statistics of videos uploaded to that channel, stores tokens and statistics locally, and never sells or shares data with third parties. Access can be revoked at any time at myaccount.google.com/permissions. Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
